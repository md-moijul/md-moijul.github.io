## What to build

Configure the build process to support standard History API routing (Clean URLs) on GitHub Pages. This involves ensuring assets are served from the root and that GitHub Pages can handle direct navigation to sub-routes without 404ing.

## Acceptance criteria

- [x] `vite.config.ts` updated to use `base: '/'` (or the appropriate absolute path for the production environment).
- [x] Build process automatically generates a `404.html` file in the output directory that is a copy of `index.html`.
- [x] Local production preview (`npm run preview`) correctly loads assets.

## Blocked by

- None - can start immediately
