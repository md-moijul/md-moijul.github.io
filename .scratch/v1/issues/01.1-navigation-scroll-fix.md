# Issue 01.1: Fix Section Navigation and Scroll Behavior

**Status:** ready-for-agent

## Parent
PRD-V1.md

## Reference
Follow-up to **Issue #01 (Routing Infrastructure)**. The introduction of `vue-router` in Hash Mode broke traditional anchor-based navigation because the router now manages the URL hash.

## What to build
Implement a programmatic navigation handler to restore smooth scrolling and section navigation across the app.

1.  **Programmatic Navigation**: Update `NavigationPanel.vue` to use a `scrollToSection` function instead of raw `href` anchor tags.
2.  **Lenis Integration**: Ensure the navigation handler uses the `lenis` instance (from `useLenis`) for smooth scrolling.
3.  **Cross-Page Support**: Handle navigation from `ArchiveView` back to specific sections on `HomeView`. If the current route is not `/`, the handler should navigate to `/` first and then trigger the scroll.
4.  **Intersection Observer Sync**: Ensure the existing `activeSection` highlighting logic remains compatible with the new navigation method.

## Acceptance criteria
- [ ] Navigation links on the Home page trigger smooth scrolling to the target section.
- [ ] Navigation links clicked from the Archive page successfully redirect to the Home page and then scroll to the target section.
- [ ] Active section highlighting in the sidebar continues to work correctly as the user scrolls.
- [ ] No "double hash" conflicts in the URL (e.g., avoid `/#/#projects`).

## Notes
- This is a critical fix to restore the user experience broken by the routing infrastructure update.
- Consideration should be given to how Lenis is initialized and accessed within the `NavigationPanel`.

## Review Findings & Technical Debt
Based on the review of Issue #01:
- **Import Aliases**: Fix violations of the `@/` import alias convention in `App.vue`, `router/index.ts`, and `HomeView.vue`.
- **Scroll Reset**: Implement scroll-to-top logic when switching between `HomeView` and `ArchiveView`.
- **Routing Conflict**: Explicitly handle the conflict between `createWebHashHistory` and the previous anchor-based links.
