## What to build

Refactor `ArchiveView.vue` into a full-screen modal-style overlay with a refined layout and improved usability. The view features a fixed header (with title and "Go Back" button) and a scrollable table with sticky headers. Background navigation is hidden when the archive is active to maintain visual integrity with the transparent theme.

## Final Implementation Details

The project archive uses a custom **Grid-based Table** layout instead of standard HTML tables to ensure consistent column ratios and clean content clipping during scroll.

- **Layout:** Uses `display: grid` with fractional units (e.g., `grid-cols-[100px_2fr_4fr_3fr_120px]`). Every grid cell has `min-w-0` to prevent content-driven overflow and misalignment.
- **Sticky Header:** The header uses `sticky top-0` inside the vertical scroll container to maintain visibility and horizontal alignment during scroll.
- **Content Clipping:** A `mask-image` with a linear gradient is applied to the rows container to provide a clean "cutoff" transition at the header boundary.
- **Alignment Integrity:** Shared vertical scroll context with `scrollbar-gutter: stable` ensures header and rows stay perfectly aligned even when the scrollbar appears.
