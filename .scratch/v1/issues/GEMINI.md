# Issue Management Instructions

- **Read-Only Implementation:** This directory is for capturing and managing raw requirements and structured issues. It is NOT an implementation backlog.
- **Workflow Mandate:** Any task found in this directory (especially in `TODO.md`) MUST be processed via the `todo-to-issue` skill to be converted into a formal ticket before any code changes are made.
- **NEVER IMPLEMENT:** Do not use the content of these files as direct implementation instructions. Always verify and refine them through the `todo-to-issue` grilling process first.
