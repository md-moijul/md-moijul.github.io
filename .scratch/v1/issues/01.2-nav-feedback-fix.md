# Issue 01.2: Navigation Feedback and Full-Width Archive Layout

**Status:** open

## Parent
.scratch/v1/issues/01.1-navigation-scroll-fix.md

## What to build
This issue combines visual feedback improvements with a layout adjustment for the Project Archive based on user preference.

1.  **Full-Width Archive Layout**:
    *   Revert `App.vue` layout to hide `NavigationPanel` on the `/archive` route.
    *   Make the `main` content area `w-full` when on the `/archive` route.
2.  **Archive Page Cleanup**:
    *   Remove section-specific navigation links from `ArchiveView.vue`.
3.  **Refactor IntersectionObserver**:
    *   Switch from ratio-based detection to position-based detection using `rootMargin`.
    *   Set `rootMargin` to trigger when a section reaches the top ~20% of the viewport (e.g., `0px 0px -80% 0px`).
4.  **Optimize Scroll Performance & Responsiveness**:
    *   Reduce Lenis scroll duration to `0.8s`.
    *   Ensure the `activeSection` is updated immediately after a programmatic scroll is triggered.
    *   **Set "about" as the default active section** in `NavigationPanel.vue`.
    *   **Remove all artificial delays (`setTimeout`)** from `App.vue`, `NavigationPanel.vue`, and `useScrollTo.ts`.
    *   Use `nextTick` where necessary to ensure DOM readiness without arbitrary delays.

## Acceptance criteria
- [x] Archive page is full-width (no sidebar).
- [x] Active link styling (before/after brackets) appears consistently as the user scrolls.
- [x] The correct section is highlighted when it reaches the top of the viewing area.
- [x] Clicking a nav link results in a snapier, more responsive scroll transition.
- [x] Archive page does NOT include section navigation links.
- [x] "About" is highlighted by default on initial load.
- [x] No artificial `setTimeout` delays in navigation or layout logic.
