## Parent
Issue 16: Interactive Stack Badges

## What to build
Refactor the `stack` query parameter handling in `useStackFilter.ts` to use a single comma-separated string instead of multiple keys. This ensures the URL remains clean and readable (e.g., `?stack=Vue,TypeScript,Vite` instead of `?stack=Vue&stack=TypeScript&stack=Vite`).

The implementation should:
- Detect and normalize legacy array-based parameters (if present) into the new format.
- Preserve the order of technologies based on click sequence.
- Use standard URL encoding for special characters.
- Update unit tests to verify the new behavior.

## Acceptance criteria
- [ ] `useStackFilter` reads and writes `stack` as a single comma-separated string in the URL.
- [ ] Toggling technologies updates the string while preserving existing selections.
- [ ] Removing all technologies deletes the `stack` key from the URL.
- [ ] Special characters (e.g., `C++`) are correctly encoded and decoded.
- [ ] Unit tests in `useStackFilter.test.ts` pass with the new format.
