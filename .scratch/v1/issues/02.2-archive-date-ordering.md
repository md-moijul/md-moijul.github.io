## What to build

Implement descending date-based sorting for the Project Archive list. Projects should be ordered from newest to oldest based on their `date` field in `src/assets/data.ts`. 

- **Sorting Logic:** 
    - Projects with a `date` should be sorted descending (newest first).
    - Projects without a `date` should be treated as the oldest and placed at the bottom of the list.
    - Sorting should be performed dynamically in the `ArchiveView` component (or the router's props logic) to avoid affecting other views like `HomeView`.
- **Tie-breaking:** If two projects have the same date, maintain their original relative order from the `projects` array.

## Acceptance criteria

- [x] `ArchiveView` displays projects sorted by year/date in descending order.
- [x] Projects without dates appear at the end of the list.
- [x] Sorting does not affect the order of projects on the Home page (e.g., "Featured Projects" section).
- [x] The "Year" column in the table correctly reflects the sorted order.
